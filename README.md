# 🎬 Movie Tracker App

A React-based movie search application that allows users to search movies and view detailed information using the OMDb API.

## 🚀 Features

* Search movies by title
* View movie posters and basic details
* Display detailed movie information
* Debounced search for optimized API calls
* Responsive and component-based UI

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* Axios
* Styled Components
* OMDb API
* GitHub
* Vercel

## 📂 Project Structure

```text
src/
├── App.js
├── components/
│   ├── MovieComponent.js
│   └── MovieInfoComponent.js
```

## ⚡ Key Concepts Used

* React Hooks (useState, useEffect)
* API Integration with Axios
* Props & Callback Functions
* Conditional Rendering
* Debouncing
* Component-Based Architecture

## 🔄 Application Flow

Search Movie → API Call → Display Results → Select Movie → Fetch Details → Show Complete Information
